# Reuse Campus

English-language Kyoto University student marketplace prototype.

The published index.html bundles the stylesheet, scripts, all 18 product photographs, and both campus covers so no image folder or third-party image host is needed at runtime. Google Fonts is optional; system font fallbacks are included.

Accounts and listings are stored in this browser only. Student identity is self-declared; this is an independent student prototype.

Original editable source: https://github.com/wangqiran52-sketch/my-site
